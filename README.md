# Moviebox

Projeto acadêmico desenvolvido para a disciplina de Programação Avançada da UNIVATES.

## Sobre

O Moviebox é um sistema inspirado no Letterboxd para gerenciamento de filmes e listas personalizadas.

## Stack

- Java
- Maven
- PostgreSQL
- JDBC

## Como executar

### Requisitos

- Java (JDK)
- Apache NetBeans
- PostgreSQL

### Execução

1. Clone este repositório.
2. Abra o projeto na sua IDE (preferencialmente NetBeans).
3. Aguarde o Maven carregar as dependências.
4. Configure o banco de dados PostgreSQL.
5. Compile e execute a aplicação.
